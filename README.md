# Personal Blog Web

A static personal blog built with React. Blog data lives in `src/blog.js` and is passed down to components as props.

## Component Tree

```
App
├─ Header
├─ About
└─ ArticleList
   └─ Article
```

## How to Run

```bash
git clone <your-repo-url>
cd Personal-blog-web
npm install
npm run dev
```

Open the link shown in the terminal (e.g. http://localhost:5173).

## Run Tests

```bash
npm test
```
